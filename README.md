# 🏦 Bank Management System - Python

A simple and secure banking system made with Python for BCA students.

## ✨ Features
- Create New Account
- Deposit Money
- Withdraw Money
- Check Balance
- View Transaction History

## 🛠️ Tech Used
- Python 3
- File Handling for data storage

## 🚀 How to Run
1. Download the file `bank_management.py`
2. Run `python bank_management.py` in terminal
3. Follow the menu
